Для запуска фронтенда
`npm run dev -- -H 0.0.0.0`

Для запуска бэкэнда:
`uvicorn api:app --reload --host 0.0.0.0 --port 8000`

*После запуска необходимо подождать минуты 4 до полного запуска всех модулей!!!*
